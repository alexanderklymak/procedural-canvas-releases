# Procedural Canvas — updates

This repository hosts the released versions of **Procedural Canvas**, a board for Houdini.

**[⬇ Download the latest version](https://github.com/alexanderklymak/procedural-canvas-releases/releases/latest)** — open it and download the `.zip` under **Assets**.
All versions with their notes are listed under [Releases](https://github.com/alexanderklymak/procedural-canvas-releases/releases).

Installed copies of the plugin read `latest.json` and update themselves. To install, follow `INSTALL.txt` inside the archive.
A license key is required: buy the plugin on its product page. Support: projectcanvas.support@gmail.com
